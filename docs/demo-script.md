# 8-15 minute demo script

1. Introduce the product: a tenant-isolated RAG assistant whose LLM-facing layer is separate from deterministic decisions.
2. Register the fictional University organization and show the empty overview.
3. Upload `Scholarship_Rules.pdf`; call out server limits and READY status.
4. Create an assistant, copy its newly-issued URL and show the iframe snippet.
5. Ask the minimum-GPA direct question; point out the page citation.
6. Ask the multi-condition second-year/GPA/sports question; show Boolean, Choice, and Score evaluations, parallel execution, and deterministic combination.
7. Ask an unsupported placement question; show the unable-to-answer response.
8. Register fictional Hospital in a separate browser profile, upload its policy PDF, and create its assistant.
9. Ask the University assistant about a Hospital-only rule; show it cannot retrieve it.
10. Open Swagger, the architecture diagram, and the decision-engine documentation; close with mock-mode testability and production OpenAI configuration.
